## 📌 Overview

This repository contains the source code for my professional resume, designed in **LaTeX** using the **XeLaTeX** engine. It features a modern, clean, single-column layout optimized for **Applicant Tracking Systems (ATS)**.

### ✨ Highlights
- **Engine:** XeLaTeX with `fontspec` typography.
- **Font:** Carlito (Calibri-metric-compatible, highly readable and standard ATS-compliant).
- **Structure:** Clear sections for Professional Summary, Experience, Skills, Featured Projects, Education, Certifications, and Languages.
- **Format:** Clean single-column layout without complex tables or graphics that hinder ATS parsers.

## 💻 How to Compile & View

### Option 1: VS Code / Antigravity IDE (Local)
1. Ensure **MiKTeX** or **TeX Live** is installed on your system.
2. Install the **LaTeX Workshop** extension in VS Code.
3. Open `saidur_cv.tex` and press `Ctrl + Alt + V` to view the live PDF preview.
4. The file includes `%!TEX program = xelatex` so it compiles automatically using XeLaTeX on save (`Ctrl + S`).

### Option 2: Overleaf (Online)
1. Import or paste `saidur_cv.tex` into a new project on [Overleaf](https://www.overleaf.com).
2. Go to **Menu** (top-left) $\rightarrow$ **Compiler** $\rightarrow$ select **XeLaTeX**.
3. Click **Recompile** to preview and download the PDF.
